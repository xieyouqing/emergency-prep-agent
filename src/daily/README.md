# daily/ —— 日常问答模块（未实现）

职责：单入口里的「日常」分支——用户有具体问题时在线检索，答 + 来源；查不到或来源不在清单内则转渠道。

约定（与另外两个模块的边界）：
- **不读写自检数据**：日常模块不碰 `answers` / `needsHelp`，避免两套状态互相污染。
- **失败即降级**：网络 / 来源不可用时转渠道（号码、网址），不是「答不上来」（docs/01 §2 三层降级）。
- **来源协议**：允许来源清单、必带来源与获取日、冲突取保守、用药类不判断（docs/01 §4）。
- **入口由 core 决定**：单入口默认进自检；进日常的条件与按钮数在 docs/01 §2 定，未定前不实现。
