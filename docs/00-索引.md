# docs 索引

> 八份文档，各自「谁读、什么时候读、判断什么」。找东西先看这张表。
> 粒度判据见 `AGENTS.md` §9「文档粒度判据」：要能验 / 要能实现 / 要能查。

| # | 文件 | 读者 | 什么时候读 | 判断什么 |
|---|---|---|---|---|
| 00 | 索引（本文） | 所有人 | 找不到文档时 | 该看哪份 |
| 01 | `01-需求基线.md` | 交付者、评审 | 开工前、交付前 | **什么算对**（可观察行为 + 验收） |
| 02 | `02-数据契约.md` | 实现者 | 改数据结构、改状态时 | 字段与规则对不对 |
| 03 | `03-任务与验收.md` | 实现者 + 交付者 | 排任务、交付验收 | 做没做、验没验 |
| 04 | `04-数据来源.md` | 交付者、评审 | 质疑来源、扩库前 | 来源可信吗、边界在哪 |
| 05 | `05-知识库设计.md` | 实现者 | 建库、改检索时 | 怎么建、门槛是什么 |
| 06 | `06-知识库现状.md` | 交付者 | 想知道「库里有什么」 | 覆盖了什么、缺什么 |
| 07 | `07-V1.0-形态.md` | 产品、评审 | 定范围、对外讲 | **V1.0 到哪为止** |
| 08 | `08-测试记录.md` | 交付者 | 每次跑完断言 | 跑过没有、几条、结果 |
| 09 | `09-审核待办.md` | 实现者 | 排 bug、修遗留 | 哪些审查发现还没修 |

## 快速路径

- 想知道**产品要什么** → 01
- 想知道**数据怎么存、什么算非法** → 02
- 想知道**还差什么、做到哪了** → 03
- 想知道**知识库能答什么** → 06，来源可信度看 04
- 想知道**V1.0 边界** → 07
- 想知道**测过没有** → 08

## 不记的东西（§9）

过程推演（除非该决策会被重新提出）、代码已表达的东西（签名/类型别抄）、没结论的讨论。
