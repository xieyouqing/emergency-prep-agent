# 04-数据来源 — 数据来源、时效与交叉验证

> 抓取日：2026-11-04
> 规矩：外部数据必须带**来源分级、抓取日、口径**；没有权威来源时做**交叉验证**并标注；未核实的标「待验证」。

## 0. 分级定义

| 级别 | 含义 | 能不能当规则 |
|---|---|---|
| `official` | 官方原文直接写明 | 能 |
| `consensus` | ≥2 个权威（应急管理部 / 消防救援局 / 红十字会）表述一致 | 能 |
| `cross-checked` | ≥2 个**独立官方来源**表述一致，但不是最终权威口径 | 能，但注明来源 |
| `inferred` | 我方推断，无外部依据 | **不能**，必须真人验证 |

**结论**：14 项中 11 项在另一份官方指南中有一致表述 → 条目名单可信度较高（`official` + 交叉验证通过）。
**差异**：广东多出「家庭应急卡」「安全帽」「破窗器」「雨衣保暖衣物」；安徽多出「自救资料」「防潮垫」。

## 4. 检查判据 —— 只有 4 条升到 `cross-checked`

官方清单只写功能用途，不写检查方法。经交叉验证后：

| 条目 | 判据来源 | 级别 |
|---|---|---|
| 手电 | 两源都有「收音 + 充电 + 报警」三功能，但「摇 30 秒仍能亮」无原文 | `inferred` |
| 救生哨 | 两源都写「高频」 | `cross-checked` |
| 食品饮水 | 广东给了「每人每天 1 升、备 3 天」「每半年检查更换」 | `cross-checked` |
| 常用医药品 | 两源都写「注意有效期」 | `cross-checked`（仅有效期部分） |
| 医用材料 | 广东列明品类 | `cross-checked`（仅品类部分） |
| 其余 10 条 | 无外部一致来源（含手电的手摇判定） | `inferred` |

**待验证清单（复核 2026-11-10）**

| 条目 | 需要补什么 |
|---|---|

## 5. 一个冲突要记住

- **广东指南**：每半年检查更换一次
- **我们 §2**：90 天一轮自查

两者差 3 个月。我们更保守（90 天 < 半年），**不是错**，但要么标注来源差异，要么改成半年。这条留给需求复核（11/10）决定，不擅自改。
