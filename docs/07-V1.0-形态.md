## 1. 一句话

**单入口的家庭应急助手**：能问事、能自查、急事一键拨号。前端纯静态，后端只读检索。

## 2. 三条链路（形态以 01 为准）

```
主页（home）
├─ 问个事（daily）→ 答案页（dailyAnswer）
├─ 自查清单（check ×14）→ 分支页（unsure）→ 结果页（result）
└─ chip：我现在有急事 → 紧急页（emergency）
```

到期提醒（remind）：现在查 / 稍后 24h / 别再问。入口分流规则见 01 §2。

- 技术形态：前端四模块 + 后端零依赖检索，命令见 `AGENTS.md` §2
