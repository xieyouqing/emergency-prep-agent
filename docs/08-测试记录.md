## 怎么跑

```bash
node tools/checks.mjs        # 79 条，纯逻辑 + 出口表结构检查
node tools/checks-kb.mjs     # 8 条，读 seed.json
node tools/checks-api.mjs    # 16 条，需 python server/api.py 8001 + node tools/dev-server.mjs 8000
```

**门槛**：任一 FAIL 退出码非 0；**只判「跑通 + 不崩 + 结构对」，不判答案质量**（答案质量等上 RAG-G 后做评测集）。
